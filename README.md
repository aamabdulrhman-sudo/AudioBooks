# 📚 المكتبة الصوتية الذكية (Smart AudioBook Studio)

> **تحويل كتب ومستندات الـ PDF تلقائياً إلى كتب صوتية مفهرسة ومصنفة مع دعم الترجمة الذكية من الإنجليزية إلى العربية الفصحى.**

---

## 🌟 المميزات الرئيسية

- 📄 **تحويل مباشر وسلس (Zero-Hassle Pipeline):** اسحب وأفلت أي ملف PDF، وسيقوم النظام باستخراج النصوص وتوليد غلاف الكتاب تلقائياً من الصفحة الأولى.
- 🧠 **فهرسة وتصنيف ذكي (Gemini 3.8 Flash):** يحلل محتوى الكتاب ويستخرج:
  - عنوان الكتاب الرسمي.
  - اسم المؤلف.
  - تصنيف الكتاب (روايات، تطوير ذات، تقنية، دين، تاريخ، فكر وفلسفة، إدارة وأعمال، عام).
  - ملخص ذكي وموجز للكتاب.
- 🌐 **ترجمة آلية أدبية من الإنجليزية إلى العربية:** إذا رفعت كتاباً إنجليزياً، يقوم الذكاء الاصطناعي بترجمته إلى لغة عربية فصحى عذبة وسلسة ومناسبة للاستماع الصوتي.
- 🎙️ **نطق صوتي فخم وعالي الجودة:** قراءة بأصوات استوديو سعودية فصيحة ومريحة للاستماع الطويل:
  - **صوت حامد:** صوت رجالي عميق وفخم.
  - **صوت زارية:** صوت نسائي نقي وهادئ.
- 🎧 **مشغل صوتي مدمج واحترافي:**
  - تقديم وتأخير 15 ثانية ⏩ ⏪.
  - التحكم في سرعة الصوت (0.75x, 1x, 1.25x, 1.5x, 2x).
  - شريط تقدم تفاعلي مع دعم Range Requests للقفز السريع لأي دقيقة.
  - تحميل ملف الـ MP3 مباشرة للجوال أو السيارة.
- 📱 **واجهة مستخدم عصرية وسريعة:** تعمل على المتصفح والكمبيوتر والجوال وتدعم البحث السريع وتصفية التصنيفات.

## 🐳 التشغيل السريع باستخدام Docker (موصى به)

### المتطلبات:
- تثبيت [Docker](https://www.docker.com/) و [Docker Compose](https://docs.docker.com/compose/).

### خطوات التشغيل:
1. استنسخ المستودع:
```bash
git clone https://github.com/aamabdulrhman-sudo/AudioBooks.git
cd AudioBooks
```

2. شغّل الحاوية باستخدام Docker Compose:
```bash
docker compose up -d --build
```

3. افتح المتصفح على الرابط:
👉 **[http://localhost:8086](http://localhost:8086)**

---

## 💻 التشغيل المحلي (بدون Docker)

### المتطلبات:
- Python 3.10 أو أحدث.

### خطوات التشغيل:
1. تثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

2. تشغيل السيرفر:
```bash
python server.py
```
أو على أنظمة Windows عبر النقر المزدوج على: `start_audiobook_library.bat`.

## ⚙️ هيكلية المشروع

```text
audiobook-library/
├── static/               # الواجهة الأمامية (HTML, CSS, JS, SVG)
│   ├── index.html
│   └── default_cover.svg
├── data/                 # قاعدة بيانات الكتب المحفوظة (books.json)
├── audio/                # ملفات الكتب الصوتية المُنتجة (MP3)
├── covers/               # أغلفة الكتب المستخرجة تلقائياً
├── uploads/              # مجلد مؤقت لملفات الـ PDF المرفوعة
├── processor.py          # محرك الاستخراج، الفهرسة، الترجمة، والتوليد الصوتي
├── server.py             # سيرفر aiohttp وواجهات البرمجة (REST API)
├── Dockerfile            # ملف بناء صورة دوكر
├── docker-compose.yml    # إعدادات تشغيل الحاوية ومشاركة التخزين
├── requirements.txt      # مكتبات بايثون المطلوبة
└── README.md             # دليل استخدام وتوثيق المشروع
```
